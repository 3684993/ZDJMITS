## 实现

- Settings资源保存/激活后自动独立验证公开连接；失败不回滚已保存配置，不返回虚假PASS。
- Engine HTTP服务启动时异步验证当前代理，不拦截Engine启动，不自动重启代理或模型。
- 未配置、已停用、验证中、通过、未通过、尚未验证和证据过期分别显示。成功证据120秒后过期；TESTNET/Production和不同URL不共用证明。
- 被动排队观察保持GET只读，不额外发交易所请求；独立验证不进入交易请求队列。
- 系统设置→网络代理增加启动、重启、授权密钥、最近核验PID、失败阶段及操作结果。密钥仅驻留当前页面，不持久化或写日志。
- 后端只管理当前启用的TESTNET固定 `socks5h://127.0.0.1:20091`。恒时令牌及同源校验，拒绝额外命令字段，仅调用固定封存脚本。
- 原脚本核验OpenSSH可执行文件、启动参数、端口所有者、创建时间和收据，以Windows mutex互斥。后端另有并发锁、磁盘锁、60秒上限及审计；超时结果不明时保留锁，禁止盲目二次切换。
